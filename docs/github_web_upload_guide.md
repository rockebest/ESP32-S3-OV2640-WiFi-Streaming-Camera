# GitHub Web Upload Guide

GitHub 웹에서 업로드하는 방법입니다.

1. GitHub에서 새 Repository를 만듭니다.
2. Repository 이름 예:
   - `ESP32-S3-OV2640-WiFi-Streaming-Camera`
3. `Add file` → `Upload files`를 누릅니다.
4. 이 프로젝트 폴더 안의 파일과 폴더를 드래그해서 업로드합니다.
5. Commit message 예:
   - `Initial commit: ESP32-S3 OV2640 Wi-Fi camera streaming`
6. `Commit changes`를 누릅니다.

주의:
- 실제 Wi-Fi SSID와 비밀번호를 코드에 넣은 상태로 업로드하지 마세요.
- GitHub에는 반드시 `YOUR_2_4GHz_WIFI_SSID`, `YOUR_WIFI_PASSWORD` 형태로 남겨두세요.
